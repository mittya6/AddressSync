# ✉️ メール宛先セミコロン作成ツール（AddressSync）

**AddressSync** は、ビジネスメール（Outlook、Gmailなど）の **To / Cc / Bcc 宛先リスト作成・確認作業を劇的に効率化するWebツール** です。

メンバーをクリックするだけでセミコロン区切り（`; `）のアドレス一覧を生成できるだけでなく、**既存のメール宛先を貼り付けることで「誰が含まれているか」を逆引きチェック・ハイライト表示** できます。

---

## 📌 こんなお悩みを解決します

- 毎回のメール送信で、ToやCcに入れるメンバーをアドレス帳から1人ずつ探すのが面倒
- 役職順やチーム順など、決まった並び順で綺麗に宛先を並べたい
- 前回のメールの宛先をそのまま使いたいが、「誰が含まれていて、誰が漏れているか」を確認するのに時間がかかる
- 社外アドレスや登録外のアドレスが誤って混ざっていないかダブルチェックしたい

---

## 🎯 主な機能と使い方

### 1. クリックするだけで宛先リストを自動作成
- **操作方法**: メンバー一覧から送信したい相手をクリックしてチェックします。
- **特徴**:
  - チェックを入れた順番に関係なく、**リストの上位グループ（役職者など）から順に自動ソート**されて下の「宛先」欄にセミコロン区切りで反映されます。
  - グループヘッダーの **「全選択」** / **「全解除」** ボタンを使えば、チーム単位でまとめて宛先に追加・除外できます。
- **コピー**: 選び終えたら **「📋 コピー」** ボタンを押すだけでクリップボードにコピーされます。そのままメールソフトの To や Cc 欄に貼り付けられます。

---

### 2. 【おすすめ】貼り付けからの「逆引きチェック」＆ハイライト
受信メールや過去の送信メールの宛先欄を本ツールの「宛先」欄に貼り付けることで、宛先チェックを行えます。

- **操作方法**:
  1. メーラーなどの宛先（`山田 太郎 <taro@example.com>; jiro@example.com` など）をコピーします。
  2. 本ツールの **「宛先」** 入力欄に貼り付けます。
- **自動解析・ハイライト**:
  - テキストを自動解析し、合致する登録メンバーに**自動でチェック**が付きます。
  - 該当メンバーのカードが**黄色く点滅（ハイライト）**し、誰が含まれているかが一目で分かります。
- **登録外アドレスの検知・警告**:
  - メンバー表に登録されていないアドレスが含まれている場合、入力欄の下に **「⚠️ 登録外のアドレスが含まれています」** と警告表示されます。
  - 社外メンバーの混入チェックや、リスト未登録者の確認に役立ちます。

---

### 3. グループメール（メーリングリスト/ML）の登録・選択
「個々のメンバーではなく、チーム全体のメーリングリストを宛先に入れたい」というケースにも対応しています。

- **設定**: グループヘッダーの「メールグループ:」欄にMLアドレス（例: `dev-team@example.com`）を入力すると、自動保存されます（未入力のままでも使用可能）。
- **宛先追加**: アドレスが設定されると右側に **「宛先に追加」** チェックボックスが現れます。チェックを入れると、グループの個別メンバーに先駆けてMLアドレスが宛先欄に追加されます。
- **逆引き対応**: 宛先欄にMLアドレスを貼り付けた場合も、MLのチェックボックスが自動でオン＆ハイライトされます。

---

### 4. クイック絞り込み検索
メンバー数が多い場合でも素早く見つけることができます。

- **操作方法**: 「🔍 絞り込み」ボタンをクリックして検索バーを表示し、キーワードを入力します。
- **対象**: **メンバー名**、**メールアドレス**、**グループ名**、**メールグループアドレス** のいずれかに部分一致するメンバー・グループだけをリアルタイムに絞り込みます。
- **解除**: 「✕」ボタンを押すだけで検索条件がクリアされ、元の全体一覧に戻ります。

---

### 5. メンバー一覧のカスタマイズとチーム共有
画面最下部の **「⚙️ メンバーデータの編集・確認」** をクリックすると、メンバーデータを自由に編集できる管理パネルが開きます。

- **ブラウザに自動保存**:
  画面上で編集して「💾 データを保存して反映」を押すと、ブラウザ（LocalStorage）に保存されるため、次回開いたときも同じメンバー一覧が使えます。
- **チーム内での共有（エクスポート & インポート）**:
  - **「📥 JSONダウンロード」**: 現在登録されているグループ・メンバー一覧をJSONファイルとして保存します。
  - **「📂 JSON読み込み」**: 配布されたJSONファイルを取り込むだけで、同じメンバーリストを再現できます。新入社員へのアドレス帳共有やチーム統一のテンプレート配布に便利です。
- **初期化**:
  「初期データに戻す」を押せば、いつでもサンプルの初期状態へ復元できます。

## 💡 便利な使い分けテクニック

| 利用シーン | おすすめの使い方 |
| :--- | :--- |
| **毎朝の定例報告メール** | 所属グループの「全選択」を押し、お休み・不在のメンバーだけチェックを外して「📋 コピー」 |
| **重要メールの送信前確認** | 送信直前のメーラーの宛先を全選択してコピー → 本ツールに貼り付け。ハイライトで役職者の漏れがないか、登録外のアドレスが含まれていないかを確認 |
| **プロジェクトメンバーの招集** | 「🔍 絞り込み」でプロジェクト名や氏名を部分検索して順次チェック |

## 🚀 すぐに使うには

**インストールや初期設定、サーバー起動は一切不要です。**

1. ダウンロードまたは配置したフォルダ内の `index.html` をダブルクリックして開きます。
2. お使いのブラウザ（Google Chrome、Microsoft Edge など）ですぐに利用を開始できます。
3. インターネット接続が不要なローカル完結型のため、セキュリティが厳しい環境やオフラインでも安全にご利用いただけます。
